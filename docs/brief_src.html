2. How each component works

  • Ingestion: Repairs UTF-8 BOM/UTF-16/cp1252 mojibake, sniffs CSV/TSV/│-box dialects, parses nested/coded/stringified JSON, FHIR R4, HL7 v2, and notes; streams files >2 MB and quarantines symlinks, binaries, or >64-deep JSON without raw copy.
  • Multilingual detection: Schema lexicons + value-shape inference + pyDeid/Philter/medSpaCy context rules (Addison's, CPAP, Dr./SN, C/O/S/O, Bharti No vs admission) across 9 Indic scripts (\u0900–\u0D7F) + Latin + Hinglish.
  • Identity & pseudonyms: Scalar-first blocking, Odia/Assamese/Indic phonetic skeletons, honorific stripping, and whole-cluster vetoes (gender, birth year, Aadhaar/ABHA/PAN). Emits 50-bit Crockford PSN-XXXXXXXXXX via HMAC-SHA256.
  • Adaptive privacy: Pools each patient's QIs across all records, applying ARX k_dist (5-yr band + district drop at k≥5 before 10-yr widening), rare-ICD (≤3) / age ≥80 escalation, and per-patient HMAC date shifts (±180d) preserving LOS/order.

3. USP & Security design (encryption at rest)

  • USPs: (1) Pooled longitudinal ARX privacy over linked multi-file patients vs naive row masking; (2) Zero-false-merge cluster firewall beating Splink-TF (FM=0 across dev, H1–H21, 9961–9964 vs 105–2,902); (3) Pure Python stdlib (0 LLMs); (4) Assurance 3.0.
  • Security & encryption at rest: Official main.py keeps raw inputs & linkage graphs in RAM only, emitting PII-free counts on stdout (channels_clean.stdout_stderr=true) and writing solely finalized sanitized/, records.jsonl, and SHA-256 report.json via atomic replace (0 temp files left). Transient deletion is not encryption, and HMAC is pseudonymization; persisted archives require host OS/volume encryption (LUKS/KMS). RAKSHA_SECRET is env-only (exit 2 if empty); dev UI takes synthetic data only.

6. Honest limitations

  • Security & adversarial boundary: Tested against ATTACKS.md and local invariants on macOS Python 3.14 (and Python 3.9 compat; Docker inactive); no finite test proves anonymity, and rare ICD-10 + LOS preservation keeps rare-profile A5 non-zero.
  • Conservative linkage & shared landlines: Unsupported scripts & ambiguous singletons abstain (`s9903`/`s9904` false merges cut `32/3 -> 0/0` in OMEGA); local substring audits can flag benign lab counts/doctors.
